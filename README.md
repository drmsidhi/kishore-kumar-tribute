# Kishore Kumar Tribute Website

A Next.js (App Router) + Tailwind CSS tribute site dedicated to Kishore Kumar.

## Features
- **Retro Vintage Theme:** Customized palette (vinyl dark, gramophone gold, warm amber, vintage cream).
- **Hero Section:** CSS-animated spinning vinyl record motif.
- **Interactive Jukebox:** Category/mood filterable discography list.
- **Cinematic Archive:** Highlighting his roles as actor, director, and composer.
- **The Kishore Chronicles:** Notable trivia and legendary anecdotes.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
